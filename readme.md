# Web para pruebas

Plugin bilingue para identificar sitios de pruebas, controlar el correo saliente y activar actualizaciones automáticas.

## Funciones

- Aviso «Web para pruebas» / «Testwebsite» en español y alemán, según el idioma de WordPress.
- Aviso en frontend y escritorio, configurable y ocultable por usuario durante 30 minutos.
- Bloqueo predeterminado del correo saliente, lista permitida o activación completa. Los bloqueos generan avisos en el escritorio durante 24 horas.
- Actualizaciones automáticas activadas para WordPress, plugins, temas y traducciones.
- WP-Cron permanece activo para que funcionen las actualizaciones y tareas programadas. XML-RPC queda desactivado.
- Una opción de configuración; no crea tablas ni archivos de datos.
- Consulta las releases de `TaisaDigital/web-para-pruebas` y ofrece el ZIP `web-para-pruebas.zip` como actualización en WordPress.

## Instalación

Subir la carpeta `web-para-pruebas` a `wp-content/plugins/` y activar el plugin. Configurar en **Ajustes > Web para pruebas**.

## Compatibilidad

Requiere WordPress 6.2 o posterior y PHP 7.4 o posterior.
